# Function Hall Booking - Payment Version

Includes:
- Function hall selection
- Booking date
- Chairs / without chairs
- Decoration
- Veg / Non-Veg food
- Guest count
- Automatic total
- Demo payment methods: UPI, Card, Net Banking, Pay at Hall
- Demo booking confirmation
- Java JDBC + MySQL starter
- Node.js supporting service

IMPORTANT:
The frontend payment is only a demo. It does not process real money and must not be used with real card credentials.

Setup:
1. Run database/functionhall.sql in MySQL.
2. Change the MySQL password in DBConnection.java.
3. Open backend as a Maven project.
4. Run Main.java to test JDBC.
5. Open frontend/index.html.
6. For Node service, open terminal in node-service and run:
   npm install
   npm start
